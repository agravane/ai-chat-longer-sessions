# Fresh-chat handoff

Use this when the chat is long, you are near a message limit, or you want to switch tools.
Paste it into a **new** chat. Do not attach the old conversation.

```
Continue this job. Do not ask for the old chat.

Job:
Decisions already made:
Still open:
Finished text lives in:
Next step:
```

Fill those five lines yourself, or ask the current chat: "Give me the 5-line handoff from my instructions."

Then:

1. Save anything worth keeping into your work log before you leave the old chat.
2. Open a new chat in the same tool, or in another tool that has the same custom instructions.
3. Paste only the filled handoff, plus the one document the next step needs.
