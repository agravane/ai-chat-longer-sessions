# For everyone (no coding required)

This is the shareable setup for people who use AI chat and do not write code.
It has no names, machines, or projects from anyone else. Fill in the blanks so it matches your work.

You do not need GitHub or an account on this repository. For the optional git tracking you will paste a few commands into a terminal; the AI walks you through it.

## What you get

| File | You use it |
|---|---|
| [PASTE-THIS.md](PASTE-THIS.md) | Once. Paste the block into the AI tool's custom instructions. |
| [FRESH-CHAT.md](FRESH-CHAT.md) | Whenever a chat gets long, or the site says you are out of messages. |
| [GIT-BASICS.md](GIT-BASICS.md) | Once, to set up a Dev folder and checkpoints for all your projects. |
| [WORK-LOG.md](WORK-LOG.md) | A note you keep (Notes, Docs, Word). The chat is not your only copy. |

## Set it up (about 10 minutes)

1. Open [PASTE-THIS.md](PASTE-THIS.md). Fill the five blanks in your own words.
2. Paste that whole block into the tool's standing instructions:
   - Claude: a Project, then Project instructions
   - ChatGPT: Settings, Personalization, Custom instructions
   - Gemini: a Gem
   - Grok: Customize, Custom instructions
   - Any other chat: whatever that product calls "custom instructions" or "system prompt"
3. Copy [WORK-LOG.md](WORK-LOG.md) into a note you control. One note is enough.
4. Start a **new** chat. Ask: "What rules are you following?" You should hear the habits from the paste, including the blanks you filled.

## Habits that save the limit

Web chat resends the whole conversation on every reply. A long thread burns the monthly cap even when each question is small.

1. One job per chat. Finished, or switching topics? Start a new chat.
2. Do not paste the old thread back in. Use the five-line handoff in [FRESH-CHAT.md](FRESH-CHAT.md).
3. For a big job, say "plan only, wait for my OK" before it writes the whole thing.
4. Ask for the finished piece in a form you can save (a letter, a list, a checklist), then put that in your work log.
5. Passwords, payment details, medical or legal records, and anything you would not email a stranger stay out of the chat.

## When the web plan runs out

A new chat with the five-line handoff uses far fewer messages than continuing a huge thread.
The same paste works in a second tool (ChatGPT, Gemini, Grok, Copilot) if one site is locked.
You do not need an API key or an automated workflow for that.

Write the result into your work log before you close the chat. The website history is a poor filing cabinet.
